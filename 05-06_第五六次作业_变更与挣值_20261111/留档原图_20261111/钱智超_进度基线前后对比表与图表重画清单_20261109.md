## 五、图表重画清单（钱智超执行，逐项可验收）

1. **删掉全部编码/开发/测试活动**，改回本组 28 项文档与设计工作包（张天乐 T02 表 2 逐行照抄）。
2. **WBS 编号统一**到 `1.1.1 / 2.1.1 / 4.1.1 / … / 3.3.3` 体系，与网络图 AON v2、张天乐底表一致。
3. **超期倍数改 ×2.0**（3.2.2：2.03 → 4.06 天），删掉「超期×1.5: 9d」。
4. **赶工压缩量改 2.05 天**（0.55 / 0.65 / 0.85），删掉「赶工-1d」「追回 2d」。
5. **里程碑只用 M1 = 8.24、M2 = 22.73**，删除 10-23 / 11-05 两个自定义里程碑；交付截止标第 31.00 天（11-12）。
6. **条长一律 = TE′**（两位小数），不取整数 D；横轴改为「进度坐标第 N 天」并可附日历双标尺。
7. **补关键路径高亮**（13 项关键活动），补 4 条 A7 补入的 FS 箭线，补齐 AON v1 右端被裁切的 1.1.2 / 1.2.2 / 1.3.2。
8. **补依赖关系箭线**（课本 Ch6 slide 34：黑菱形=里程碑、细横条=任务工期、箭头=依赖）。
9. **出前后对比**：至少给「B1 原基线 / S3 变更后 / 压缩后」三条工期对照（tracking Gantt，课本 Ch6 slide 40、59），并把本报告表 1、表 2 直接附在图上或紧邻页。
10. **附全 AON 复核结论**：蒋诗韵 §3.1 明确「非关键分支可能在压缩后变为关键」，须重新正推/反推 ES/EF/LS/LF/TF 后再确认 30.55 天；不能只画主链就宣称完工。
