# 成员描述与分工（RACI）

## 一、RACI 说明

- **R（Responsible）**：具体执行者，实际完成该项交付物。
- **A（Accountable）**：最终负责人，对该项交付物的质量与按时交付负责，**每项交付物有且仅有一个 A**。
- **C（Consulted）**：执行前需要征求意见的成员。
- **I（Informed）**：需要被告知结果但不直接参与执行。
