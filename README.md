# 医院门诊智能应答与对话系统

> 软件项目管理课程第一次作业
> 面向医院门诊场景，设计一套基于模拟知识库的智能咨询与对话系统原型方案。

## 一、本次作业范围

本次作业为课程设计阶段的需求与建模交付，仅包含以下内容：

- 项目需求说明书（业务模型与功能范围）
- 团队分工与 RACI 责任矩阵
- 项目管理十大知识域落地分析
- 项目预期目标分析
- 4-Frame（Bolman & Deal）全方位架构分析
- 项目初步计划（阶段划分与里程碑）
- 六张 UML 业务图 + 三张项目管理图

**不包含**：代码开发、真实系统接口、部署运维、商业化落地。

## 二、项目边界

本系统为课程设计原型方案，基于**模拟知识库**完成文本问答的需求设计与 UML 建模：

- 系统仅模拟门诊流程咨询与知识库问答；
- 不提供疾病诊断、处方建议；
- 不接入真实挂号、缴费、报告查询、医保结算系统；
- 不处理真实病历与患者身份数据；
- 不提供诊疗建议，未命中问题引导线下咨询。
