## 二、设计理由

1. **变更处理是本次最重的定量增量，沿用三、四次的"建模-求解-落地"三段式**：张天乐（扰动法出身）设情景算影响 → 王宇坤（DP 双目标框架现成）做赶工决策 → 蒋诗韵（资源预分配 v2）给资源落地方案，三人接力但互不重叠。
2. **进度基线不拆人**：网络图 + 甘特图前后对比全归钱智超，他是 AON v2 和甘特图 v2 的原作者，改自己的图交接成本最低；同时天然承担全组口径一致性（见下"预防针"）。
3. **挣值线双人闭环**：詹少希（成员 Excel/数据表经验）做 PV/AC 数据底表 → 何亭玉（蒙特卡洛可视化经验）算指标出图，数据与展示分离，便于交叉复核数字。
4. 杨卓屹保持总审 + PPT 唯一编辑铁律不变，另加一块变更管理流程章节（与项目管理计划 §3.5/§3.6 衔接）；林泽楷只做讲稿，不做 PPT。

## 五、做题要点与全组口径（给所有负责人）

1. **口径铁律（P1 预防针）**：全组统一 TE′ 口径（能力系数表引用台账第 2 条）；新甘特图条长必须 = TE′，超期情景在 TE′ 基础上 ×1.5~2 叠加，避免重演上次"甘特图与三点估算不一致"的 P1。
2. **变更情景要可复算**：写明选哪个关键路径任务、原计划工期、实际执行 = 原工期 × 多少倍、发生在计划时间的哪一天（约 2/3 处），全部给出数字来源，不写"假设延误"一笔带过。
3. **赶工手段对照课件**：压缩工期可用赶工（crashing，加资源花钱）与快速跟进（fast tracking，并行化加风险）两类，王宇坤 DP 里建议以"成本增量最小、工期恢复最多"为目标函数，与 v1.1 的双目标框架同构。
4. **挣值口径**：PV = 计划工作预算成本，EV = 已完成工作 × 预算，AC = 实际花费；CPI = EV/AC，SPI = EV/PV；截止点建议取"计划时间 2/3 处"与变更处理完成点两处分别算一遍，正好与要求①形成叙事闭环。
5. **图表要求**：老师明确要求"用图、表等进行展示"——至少出：挣值 S 曲线（PV/EV/AC 三线）、CPI/SPI 随时间变化图、压缩前后甘特图对比表。配色沿用主绿 5E9A80 系。
6. **TBD 不进终稿**：第五次作业要求确认前，凡涉及"完善第五次作业"的表述一律标 TBD，确认后回填。
