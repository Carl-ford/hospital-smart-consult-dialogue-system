## 一、钱智超 —— ①网络图 + ③三点估算表 + ④调度计划与甘特图

### 任务 ①：网络图（10-22 定稿）
- 基于你第二次作业的**细化 WBS**，取最底层工作包（约 20-40 个）作为活动，画 **AON 节点图**（单代号）。
- 每个节点标：任务编号（**必须与 WBS 编号一致**，如 1.2.3）、任务名、工期。
- **标注 2-3 个里程碑**（老师硬性要求）：建议「WBS 与章程批准」「系统原型方案评审通过」「提交作业/项目收尾」。里程碑用菱形或双框节点，与普通任务视觉区分。
- 箭线标依赖关系（FS 为主，允许少量 SS/FF，需注明）。
- **用关键路径法算出 ES/EF/LS/LF**，关键路径上的任务用红色/加粗标出（上次甘特图漏关键路径高亮，这次两个图都要有）。
- 产出：`diagrams\网络图_AON_v1.png`（PlantUML 或 drawio 皆可，.puml/.drawio 源文件一并交 `diagrams\source\`）。

### 任务 ③：三点估算表（10-23）
- 对网络图中每个活动给三列：乐观 a、最可能 m、悲观 b（单位：人天）。
- **每个任务的三点必须写明依据**，三要素各占一列可追溯：
  - 难度系数：技术难度 1.0 / 1.2 / 1.5 三档，说明该任务为何取此档；
  - 性格因素：引用詹少希的能力系数表（等她 10-22 交）；
  - 风险因素：引用你风险册的 **RSK 编号**（如「受 RSK-201 影响 +0.5 天」），不许凭空给数。
- 表末加两列计算结果：期望工期 TE=(a+4m+b)/6、方差 σ²=(b−a)²/36（公式写进文档）。
- 产出：`钱智超\三点估算表_v1.xlsx` + 说明文档。

### 任务 ④：调度计划 + 甘特图（10-23）
- 调度计划文档：排期依据（正排/倒排）、资源冲突说明（某人同期双任务如何处理）、里程碑日期表。
- 甘特图：用三点估算的 TE 作为工期；**关键路径高亮**（红色条）；里程碑用菱形符号；横轴到 10-29。
- 产出：`钱智超\调度计划_v1.docx` + `diagrams\甘特图_三四次_v1.png`。

## 三、何亭玉 —— ②成本侧费率 + ②'蒙特卡洛成本估算（10-23）

### 费率表
- 8 人 × 人天费率。学生项目可假设统一费率（如 300 元/人天），或按角色分档（组长 350 / 组员 300），**假设要写明是假设**。
- 每任务成本 = Σ(人员工时 × 费率)，与蒋诗韵的表联动（她交工时，你套费率）。

### 蒙特卡洛成本估算（老师点名的方法，必须出现）
- 方法说明：以任务成本为随机变量，**假设服从三角分布**（min=a 成本、mode=m、max=b，与钱智超三点估算同源），说明为何选三角分布。
- 模拟参数：次数 ≥10000 次；给出**P50 / P80 / P95 三个分位点成本**和成本分布直方图。
- 不用真跑程序也可：可用 Excel 公式近似或截图说明计算过程；但**分布参数、分位点数值必须可复算**，不许只写一句「用蒙特卡洛得到 XX 元」。
- 产出：`何亭玉\成本估算_蒙特卡洛_v1.docx`（含费率表、分布图、分位表）。

## 五、王宇坤 —— ⑥动态规划建模（10-23 初稿）

- 按老师课件《软件项目动态规划方法》的**五步建模法**逐条写，一步不缺：
  1. **划分阶段**：k = 任务序号 1..n（按网络图拓扑序），说明为何满足无后效性；
  2. **状态变量**：f_k(x) = 将资源量 x 分配给前 k 个任务可获得的最大收益（x 的单位：人天或万元，与蒋/何的表一致）；
  3. **决策变量与允许决策集合**：y = 分给第 k 个任务的资源量，0 ≤ y ≤ x；
  4. **状态转移方程**：后向递推 f_k(x) = opt{ g_k(y) + f_{k-1}(x−y) }，k=1 时 f_1(x)=g_1(x)；
  5. **双目标函数**：老师要求**时间+成本双目标**。二选一并写明理由：加权合成 Z = w₁·T + w₂·C（给出 w 取值与灵敏度说明），或以总工期为约束求成本最优。
- g_k(y) 的构造：收益 = 该任务由能力系数加权后的工期/成本节省，参数来自③⑤②，**引用编号**。
- 附符号表（每个符号一行定义）+ 一个 3 任务 × 资源 10 单位的**手算小例子**（验证模型跑得通）。
- 产出：`王宇坤\动态规划模型_v1.docx`。

## 六、张天乐 —— ⑥'扰动法求解与数值验证（10-24）

- 输入：王宇坤的模型 + 蒋/何/钱/詹四张表的数据。
- 求解：对总资源 α 逐级递推算出最优分配表（任务×分配量×收益），给出**最优分配方案**与对应总时间、总成本。
- **扰动法（老师点名）**：对最优解每个任务 ±1 单位资源做扰动，列表证明任何单点扰动都不再改进目标值（局部最优性检验）——这是本次作业的评分亮点，表不能省。
- 结论段：最优方案 vs 钱智超原始预分配方案，差多少时间/成本（对比表）。
- 产出：`张天乐\扰动法求解与验证_v1.docx` + 计算数据表（xlsx）。
